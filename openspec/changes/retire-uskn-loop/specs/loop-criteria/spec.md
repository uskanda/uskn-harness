## REMOVED Requirements

### Requirement: 完了基準の3層
**Reason**: `uskn-loop` を廃止する（ADR-0016）。
**Migration**: テストの削除、skipの追加、検証の設定の変更の検出は `uskn-diff-check`（`diff-check`）へ移す。監査役による判定は `audit` スキル（`audit-skill`）へ移す。検証規約、`openspec validate`、tasks.mdの確認は `audit` スキルが行う。
