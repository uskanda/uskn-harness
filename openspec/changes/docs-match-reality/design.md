## Decisions

1. 現状の構成の正本は AGENTS.md の Layout にする。ADR-0001 §3 は決定の記録として同じ内容を持つが、将来の置き場（アダプタ）は ADR にだけ書く。代替案は proposal §12.2 を正本にすることだが、記録と正本が混ざって再びずれる
